# Linkcount v2

A focused URL utility for counting, inspecting, filtering and exporting links from pasted text.

## Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Radix Tooltip
- Motion
- Lucide Icons

## Features

- Total URL count
- Unique URL count
- Duplicate detection
- Domain count
- Valid / invalid detection
- Search
- Filter by status
- Copy individual links
- Copy all links
- Export TXT
- Export CSV
- Dark / light theme
- Responsive layout
- Keyboard-friendly controls
- Reduced-motion support
- Accessible labels and focus states

> Duplicate links are detected but never removed.

## Run locally

```bash
npm install
npm run dev
```

Build:

```bash
npm run build
```

## Branch target

Designed for the `Chatgpt` branch of `kainapat/url-link-counter`.
